URL Format

The mentor confirmation page accepts the following URL parameters:

/mentor/confirm?student_name=...&student_email=...

Parameters

  • student_name - Name of the assigned student (required)
  • student_email - Email of the student (required)

Integration with Email

In your mentor email template, you can include a link like this:

<a href="https://your-domain.com/mentor/confirm?student_name={{studentName}}&student_email={{studentEmail}}">
  View Your Mentee Assignment
</a>

Example Email Integration (N8N Workflow)

When sending emails through your N8N workflow, construct the URL with actual data:

const confirmationUrl = `${process.env.APP_URL}/mentor/confirm?` + 
  `student_name=${encodeURIComponent(studentName)}` +
  `&student_email=${encodeURIComponent(studentEmail)}`;
